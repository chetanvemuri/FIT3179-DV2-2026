# Where Australia Stays

FIT3179 Data Visualisation 2 (Semester 2, 2026), topic 16: Hotel and Accommodation Trends.

Live page: https://chetanvemuri.github.io/FIT3179-DV2-2026/

## Files
- `index.html` – the page (story text, layout, embeds)
- `js/*.vg.json` – one Vega-Lite specification per chart
- `js/theme.js` – shared fonts and colours for all charts
- `data/` – data loaded by the page (about 1.5 MB in total)
- `data/raw/` – original Inside Airbnb downloads (not loaded by the page)
